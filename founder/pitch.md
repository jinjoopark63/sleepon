SLEEP:ON Pro, 14일 비교 체험: 내 잠으로 직접 비교해 보고 고르는 수면음 앱.
14일 동안 하루는 일반 30분 타이머, 하루는 SLEEP:ON 방식으로 번갈아 재생됨. 휴대폰을 침대 옆에 두면 폰을 내려놓은 시각과 움직임으로 잠든 시각, 밤중에 깬 시각을 앱이 기록함(아침 체크는 선택, 워치가 있으면 워치 기록도 사용). 14일째 아침, 두 방식에서 '잠들기까지 걸린 시간'과 '밤중에 깬 뒤 다시 잠들기까지 걸린 시간'을 나란히 보여 줌. 차이가 없으면 '무료 버전이 맞아요'라고 그대로 알려 줌.
Pro 기능: 내가 잠드는 시점에 맞춰 소리를 서서히 줄임. 잠드는 시각이 매일 달라도 '폰을 내려놓은 뒤 몇 분'을 배우기 때문에 교대근무에도 맞춰짐. 밤중에 깨면 잠금 화면 버튼 한 번으로 끊긴 자리부터 작게 이어 들음.
뒤척임 자동 이어 틀기는 기본으로 꺼져 있음. 처음 3일은 소리를 틀지 않고 '이 순간에 다시 틀었을 거예요'를 아침에 기록으로만 보여 주고, 맞다고 느끼면 그때 켜면 됨. 스피커로 들을 때만 권하고, 이어폰을 끼고 잘 때는 버튼 방식이 기본임. 기록은 휴대폰 밖으로 나가지 않음.
14일 체험은 자동 결제가 없음. 계속하면 연 39,000원(월 3,250원꼴) 또는 월 4,900원. 결제 후 30일 안에 기록이 나아지지 않으면 환불을 도와드림(안드로이드는 직접 환불, 아이폰은 애플 환불 요청 화면으로 연결). 무료 버전은 기본 소리 2종과 30분 끄기 예약만 있음.
